Software guide

MacroJournal

A distraction-free writing deck with a classic-Mac shell. Ten notes, a scratchpad, a (completely optional) grammar check, real file encryption — all on a 400×300 monochrome screen, all from the keyboard. This guide walks through the features.

01Getting started

Flash firmware_rev_8.bin at address 0x0 using the web flasher at espboards.dev (Chrome or Edge, upper USB-C port). It takes about a minute and doesn't erase your notes. The deck boots into the editor; press Esc to bring up the menu bar and home screen below.

For the LLM features, open Device ▸ Drive mode, copy grammana_z.json with your API key onto the drive, and set up WiFi from Setup ▸ WiFi. Everything else works out of the box.

02The home screen

The home screen is a little Macintosh desktop. Across the top is a pull-down menu bar; below it, three quick-launch tool tiles and a notes window listing your ten notes. Arrow keys move the highlight, Enter opens it, and the action bar at the bottom shows the keys that act on the highlighted note.

Each note row shows its name (if you've set one) or its first line as a title; empty slots show - and locked notes show LOCKED. Highlight a note and press R to rename it, P to lock it, or C to clear it — the same three keys the bottom bar advertises. Press a number 0–9 to jump straight to a note, or N (or Ctrl+N from anywhere) to start a new one.

03The menu bar

Open the pull-down menu bar with Esc or the menu key — or, inside a note, by double-tapping Alt. Move between menus with ←/→, within one with ↑/↓, and run an item with Enter. Each item lists its shortcut letter on the right, so you can also just press it.

From an open menu, Esc leaves the bar and Shift+Esc (in a note) closes it and drops the cursor right back where it was.

04Writing

The editor is the writing surface. It saves automatically; the status bar shows the file, word count, and SAVED. Ctrl and GUI (the two keys left of the spacebar) are interchangeable in every shortcut.

Select by character (Shift+arrows), word (Ctrl+Shift+←/→), line, or everything (Ctrl+A). Cut, copy, and paste with Ctrl+X/C/V. Jump by word with Ctrl+arrows, or across the whole document with Ctrl+PgUp/PgDn. Full list in the cheat sheet.

05Markdown styling

Your files stay plain text, but the screen styles markdown live as you type — so a draft reads the way you mean it without any export step.

Ctrl+B and Ctrl+I wrap the current selection in markers (or drop an empty pair to type into). Italic shows as underline because the panel can't slant letters.

06The scratchpad

Press Ctrl+Shift+S anywhere — or tap the Scratch tile — to open the scratchpad, an always-there note for lists and stray thoughts. Esc returns you to whatever you were writing.

But if you have text selected, that same shortcut instead sends the selection to the scratchpad without leaving your note — a quick way to stash a line while you write. A SENT TO SCRATCH flash confirms it.

07Grammana Z

Grammana Z is an on-device assistant, powered by your choice of Anthropic, OpenAI, or Gemini. Open it from the Gramma tile, with G, or with Ctrl+Shift+C. Type a question and press Shift+Enter to send — you can keep typing while it thinks.

The whole note is the conversation, with --- lines between turns, so follow-ups keep their context. Select-all and delete to start fresh; Esc returns to your writing.

08Grammar check

Ctrl+G reviews your file — or just a selection — and lists what to fix, each with the phrase, the problem, and the correction. Ctrl+Shift+G instead hands back a corrected rewrite in your voice. Either way your original is never touched.

09Locking a note

Highlight a note on the home screen and press P (or File ▸ Lock / Unlock) to set a password. The note is re-written as real AES-256 ciphertext — plaintext never touches the disk again, so Drive Mode and sync only ever see scrambled bytes. Opening it later asks for the password.

No recovery A forgotten password means the file is permanently unreadable — that's the point of real encryption. Leaving a locked file to the menu re-locks it, so you're asked again next time.

10Dark mode & names

I on the home screen (or Setup ▸ Dark) flips the whole panel to white-on-black — handy at night, and it sticks across reboots. Everything renders inverted, including selection and markdown.

Naming things. Give a note a real name with R (or File ▸ Rename): type into the dialog, Enter saves, and the name shows on the home screen, in the Notes menu, and on the synced file. To rename the whole device, open Device ▸ Device name — the name you set shows on the home window's title bar. Both persist across reboots.

11About & storage

The Device menu has two info screens. About shows the classic Happy Mac with your device name and the firmware version; Storage is a Get-Info box with a usage gauge and the real free space on the deck. Esc returns home from either.

Sync. With WiFi and a sync URL configured, Setup ▸ Sync uploads the current note to Google Drive, and the file there is titled after the note's name. See the README for the one-time Apps Script setup.
