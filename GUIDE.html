Software guide

RighterDeck

A distraction-free writing deck. Ten notes, a scratchpad, an LLM assistant, real file encryption — all on a 400×300 monochrome screen, all from the keyboard. This guide walks through every screen.

01Getting started

Flash firmware_rev_8.bin at address 0x0 using the web flasher at espboards.dev (Chrome or Edge, upper USB-C port). It takes about a minute and doesn't erase your notes. Then press the menu key to open the home screen below.

For the LLM features, enter Drive Mode (U on the menu), copy grammana_z.json with your API key onto the drive, and set up WiFi (W). Everything else works out of the box.

02The home screen

The menu is two panels. On the left are device commands; on the right, your files. Arrow keys move a highlight in the active pane and Enter runs it — or just press the bracketed letter. The device name (RighterDeck by default) sits in the toolbar.

The file list starts with three quick tools — Scratchpad, Grammana Z, and Last Note (jumps to the note you edited most recently) — then a separator, then your ten notes. Each note shows its first line as a title; empty ones show -, locked ones show LOCKED, and > marks whatever's open. A down-chevron means there are more notes below.

03Finding a file

Press F to navigate. A row highlights in inverse video, and the left panel changes from commands to the actions for that row. Arrows move the highlight (the list scrolls); the highlight is sticky, so it stays where you left it when you come back.

Enter opens the highlighted item. For notes, D clears it and P sets or removes a password — the three tools only offer Open. F or Esc leaves navigation.

04Writing

The editor is the writing surface. It saves automatically; the status bar shows the file, word count, and SAVED. Ctrl and GUI (the two keys left of the spacebar) are interchangeable in every shortcut.

Select by character (Shift+arrows), word (Ctrl+Shift+←/→), line, or everything (Ctrl+A). Cut, copy, and paste with Ctrl+X/C/V. Jump by word with Ctrl+arrows, or across the whole document with Ctrl+PgUp/PgDn. Full list in the cheat sheet.

05Markdown styling

Your files stay plain text, but the screen styles markdown live as you type — so a draft reads the way you mean it without any export step.

Ctrl+B and Ctrl+I wrap the current selection in markers (or drop an empty pair to type into). Italic shows as underline because the panel can't slant letters.

06The scratchpad

Press Ctrl+Shift+S anywhere to open the scratchpad — an always-there note for lists and stray thoughts. Esc returns you to whatever you were writing.

But if you have text selected, that same shortcut instead sends the selection to the scratchpad without leaving your note — a quick way to stash a line while you write. A SENT TO SCRATCH flash confirms it.

07Grammana Z

Grammana Z is an on-device assistant, powered by your choice of Anthropic, OpenAI, or Gemini. Open it from the file list, with G, or with Ctrl+Shift+C. Type a question and press Shift+Enter to send — you can keep typing while it thinks.

The whole note is the conversation, with --- lines between turns, so follow-ups keep their context. Select-all and delete to start fresh; Esc returns to your writing.

08Grammar check

Ctrl+G reviews your file — or just a selection — and lists what to fix, each with the phrase, the problem, and the correction. Ctrl+Shift+G instead hands back a corrected rewrite in your voice. Either way your original is never touched.

09Locking a file

In file navigation, highlight a note and press P to set a password. The note is re-written as real AES-256 ciphertext — plaintext never touches the disk again, so Drive Mode and sync only ever see scrambled bytes. Opening it later asks for the password.

No recovery A forgotten password means the file is permanently unreadable — that's the point of real encryption. Leaving a locked file to the menu re-locks it, so you're asked again next time.

10Dark mode & naming

I on the menu flips the whole panel to white-on-black — handy at night, and it sticks across reboots. Everything renders inverted, including selection and markdown.

To rename the device, press N on the menu and type a new name into the header bar; Enter saves it as the toolbar title and drops you back into the editor. It's yours — call it whatever your writing deck should be called.
